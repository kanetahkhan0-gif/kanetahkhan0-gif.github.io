# assets/scribbles — the drawings

Your drawings, pinned to the paper. Click opens a lightbox.

Currently expected:

- `scribble-01.jpg` … `scribble-06.jpg`

Add or remove freely — edit `SITE.scribbles` in `data.js` and the masonry
re-flows. Each entry takes a `src`, an `alt` (for screen readers) and a
`caption` (the handwritten line under the pin).

Export at around **1200px on the long edge**, JPG. They display at roughly
300–400px wide, so bigger is only useful for the lightbox.
